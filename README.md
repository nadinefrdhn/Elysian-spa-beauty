ELYSIAN LUXURY SPA & BEAUTY — COMPANY PROFILE WEBSITE

Website ini dibuat untuk konsep perusahaan jasa pembuatan website dan solusi digital.
Struktur file:
- index.html       : halaman Home
- about.html       : halaman About Us
- services.html    : halaman Our Services dan formulir kontak demo
- gallery.html     : halaman Gallery dengan filter dan lightbox
- css/style.css    : seluruh styling dan responsive layout
- js/script.js     : navigasi mobile, filter gallery, lightbox, dan form demo

CARA MENJALANKAN DI VS CODE
1. Ekstrak file ZIP.
2. Buka folder "elysian_digital_agency" di Visual Studio Code.
3. Buka index.html di browser, atau gunakan ekstensi Live Server.
4. Semua menu navigasi sudah terhubung antarhalaman.

CATATAN
- Gambar dan font diambil dari layanan online, jadi koneksi internet diperlukan untuk memuatnya.
- Galeri berisi contoh konsep/demo, bukan portofolio klien nyata.
- Form kontak adalah demo front-end dan membuka aplikasi email. Sebelum website dipublikasikan, ganti hello@example.com pada js/script.js dengan alamat email perusahaan yang benar.
- Website ini belum memakai backend, database, atau sistem pengiriman formulir online.
